# Weekly Reporting

Source of truth: [../LOG.md](../LOG.md) and [../../STATUS.md](../../STATUS.md). The weekly deck is a summary of those two files, not a separate record.

## Routine

1. During the week: add entries to `docs/LOG.md`.
2. Before the meeting: update `STATUS.md` (milestones, health, risks, next steps).
3. Build a 3-5 slide deck and save it here as `week-NN.pptx` (or link the Slides URL in STATUS.md).

## Deck outline

1. Progress against milestones
2. Metrics vs JetPack baseline (once measured)
3. Risks and blockers
4. Plan for next week and decisions needed
